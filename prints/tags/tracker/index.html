Board games / Find your game / Dungeons & Dragons

D&D Death Save Tracker — slide up for a heart, down for a skull

A flat, silent death-saving-throw tracker for D&D 5e. Three captive sliders: push one UP and a red heart fills the top window (success), push it DOWN and a white skull fills the bottom one (failure), leave it centred and both stay blank. Three hearts you're stable, three skulls you're dead — the whole table can read your state from across it. Five printed parts, no glue, no screws, no dice-sized bits to lose; everything prints flat and supportless. Parametric OpenSCAD source included.

Spell-Slot Abacus — print-in-place D&D spell-slot tracker

MTG — Creature Token Tracker (P/T Wheels + Type & Ability Tiles)

A card-side dashboard for tracking a single Magic: the Gathering creature token. Two flat 0–9 spin-wheels show Power / Toughness; a row of side-loading tiles behind them name the creature's TYPE and its keyword ABILITIES. Includes the token chassis + snap-on lid + two-colour digit wheel, a storage box with engraved mana-symbol lid, and the full set of 47 creature-type tiles and 42 keyword-ability tiles. Engravings print as 2-AMS Bambu Split-to-Parts, or single-colour. No supports; print the token chassis + lid in PETG (the snap pins), everything else in PLA.
