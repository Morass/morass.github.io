Round-Brilliant Diamond Token — Board Game Gem (Parametric)

A faceted round-brilliant diamond as a tabletop game gem / resource token: scalloped girdle, straight crown flare to a flat table, and a stepped pavilion. Prints table-down with the culet pointing up, so it needs no supports. Parametric OpenSCAD source included — change the girdle diameter, facet count, and proportions to taste. Single gem plus a 4-up plate.

MTG Powerstone Token — Flip-to-Tap Crystal

Chunky 60 × 30 × 16 mm faceted crystal token for Magic: the Gathering's Powerstone artifacts. It rests flat on either octagonal face: plain side up is untapped, tap-arrow side up is tapped. Flip it instead of rotating it. Prints as one part with no supports.

Remembrall Memory Orb Earring — 3-Color Smoke-Gem Charm

A faceted smoke-gem memory orb as a 3-color earring charm: a translucent red glass orb wrapped by a gold equatorial band of porthole dots, with a gold hanging bail on top. Prints in one piece on an AMS / multi-material printer — drop in the combined STL and Split-to-Parts, or print the per-color STLs separately. ~14 mm orb, support-free, print twice for a pair.
