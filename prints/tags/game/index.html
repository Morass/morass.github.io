Domino Box — Sleeve + Tray for the Double-Six 28-Tile Set (OpenSCAD)

Two-piece storage for a full 28-tile double-six domino set. Outer sleeve (closed on 5 faces, open on one short end) + inner tray with a Ø28 mm semicircular thumb-notch on its front wall. Tiles lie flat in a 4×2 grid of 4-tile stacks (32-slot capacity). Sleeve prints with the open mouth UP — fully supportless. Engraved decorative pip pattern on every long face. Parametric SCAD lets you re-tune tile dimensions, slop, layout (piles_x × piles_y), pip pattern, or wall thicknesses.

Domino Set — Double-Six (28 tiles), 2-Colour Engraved (OpenSCAD)

Full double-six domino set: 28 tiles, 36 × 18 × 5.5 mm each, Ø2.4 mm engraved pips + centre line. Two-colour print via Bambu AMS — combined named-solid STL (Split-to-Parts) ships alongside separate body + pips STLs for non-Bambu printers. Parametric SCAD included so you can re-tune tile size, pip diameter, or face content (single-tile mode `left`/`right` lets you reprint any face).

Beach Ring-Toss Lawn Game — Scoring Target Board + Tossing Rings (sand-resting, no stakes)

A beach/garden ring-toss set: a flat sand-resting target board studded with 9 scoring pins (centre = 3 pts, 3 inner = 2 pts, 5 outer = 1 pt) plus chunky two-team tossing rings. Toss a ring underhand so it drops over a pin to score. Print two boards and set them a few metres apart. Fully parametric OpenSCAD — every diameter, height and ring size is a variable. Prints flat with no supports.

Outdoors / Beach Games

Floating Memory Tiles — Pool & Beach Sea-Creature Match Game

A 24-tile memory/pairs match game (12 sea designs x 2) that FLOATS — play it on the beach blanket or straight in the pool. Each chunky 40 mm tile has a sealed internal air cavity, so it floats at any infill setting, and the face skin is deliberately heavier than the back: drop a tile in water and it rights itself ICON-DOWN, hiding its picture. Pool memory plays itself honest. Two-colour ready: one STL with named solids, split in your slicer and assign a contrast filament to the icon inlays. No supports, no AI — pure parametric OpenSCAD.

Outdoors / Beach Games

Beach Tic-Tac-Toe in a Scallop-Shell Box — Sea-Creature Peg Game (starfish vs shells)

A pocket 3x3 peg tic-tac-toe for the beach that lives inside an openable scallop-shell clamshell box. The lid is the play board (pieces plug into its 9 holes, friction fit, so wind can't blow them off); the base is a plain storage cup, so the loose pieces can't spill. 5 starfish vs 5 scallop shells (equal counts, so whoever starts both players have a full set). Fully parametric OpenSCAD; every part prints flat with no supports.
