Stackable Lattice Basket — 4 Sizes + Parametric SCAD

Cross-stackable lattice baskets with cone-peg corner posts — any basket stacks onto any other basket. Parametric SCAD included — override basket_l/basket_w/body_h to derive any size; corner-post + peg geometry is shared so derived sizes still cross-stack with the printed ones.
