Snowflake Set — Ornament · Coaster · Fridge Magnet · Earrings · Print-in-Place Cuff (Parametric)

A family of 6-fold dendrite snowflakes from one parametric generator: a tree ornament, an openwork drink coaster, a sealed-in fridge magnet, dainty earrings, a single cord charm, and a print-in-place hinged bracelet cuff that folds off the bed already articulated and locks with a toggle clasp. All print FLAT, face-down, NO supports.
