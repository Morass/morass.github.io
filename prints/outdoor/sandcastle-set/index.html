Beach Sandcastle Kit — 8-Piece Mould & Tool Set (castle buckets + sieve, rake, shovel, tamper)

A complete kids' beach sandcastle kit: 3 stacking castle bucket-moulds (keep, tower, great hall) plus 5 sand tools — a perforated sieve-scoop, a rake, a shovel, a tamper and a detailing tool. Pack the wet sand into a mould, lift, and decorate with the tools. All parametric OpenSCAD, prints flat with no supports.
