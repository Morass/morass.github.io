Mead hall box — a Viking longhouse whose whole roof lifts off

A 199 mm Viking longhouse whose whole shingled roof lifts off, leaving a 177 x 83 x 31 mm box with the hollow roof above it. Two prints in one wood-fill filament, no supports, no hardware, nothing to glue. Every plank, knot and shingle is cut and jittered from one seed, so it reads hand-built. The roof rests on a tongue, it does not latch, so it is a table box, not a travelling one.
