Capybara Lock Box — Magnetic Two-Key Drawer Box

A drawer box that only opens when you set TWO capybara figurines on its lid pads. The capybaras are the keys — each hides a magnet that lifts a hidden loose-magnet shear pin off the drawer rail. Both keys at once = a two-capybara combination lock. Multi-color engraved lid, captive drawer, self-locking. Uses hobby disc magnets you drop in during printing. Keys included.
