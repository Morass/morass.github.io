Round-Brilliant Diamond Token — Board Game Gem (Parametric)

A faceted round-brilliant diamond as a tabletop game gem / resource token: scalloped girdle, straight crown flare to a flat table, and a stepped pavilion. Prints table-down with the culet pointing up, so it needs no supports. Parametric OpenSCAD source included — change the girdle diameter, facet count, and proportions to taste. Single gem plus a 4-up plate.

Meeple & Standee Stand Base — Friction Slot Holder for Thin Tokens (Parametric, OpenSCAD)

A weighted clip base that holds any THIN game token upright — cardboard punchboard standees, acrylic or printed silhouettes, even a card edge. The token drops into a friction slot with a flared insertion mouth; the wide footprint resists tipping in the easy-to-tip direction (across the slot). Optional vertical grip ribs pinch flimsy card so it can't flop. One slider — slot_w — tunes the slot to YOUR token thickness (~1.6 acrylic / 2.2 standard cardboard / ~7 a printed meeple slab). Prints flat, slot UP, zero supports. Single base or a batch plate.

Meeple Set — Humans & Animals

A big set of classic wooden-style meeples: six human figures (plain worker, warrior, king, wizard, archer, axeman) in several sizes, plus eight animal pawns (cat, rabbit, dog, mouse, sheep, goat, duck, horse). Chunky flat tokens that print flat with zero supports — drop-in replacements and extras for almost any board game.
